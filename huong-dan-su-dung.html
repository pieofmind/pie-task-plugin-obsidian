Pie Tasks

Quản lý công việc chuyên nghiệp trực tiếp trên file Markdown của Obsidian

🚀 1. Giới thiệu

Pie Tasks là một plugin mạnh mẽ cho Obsidian, giúp bạn quản lý công việc dưới dạng Bảng Kanban, Danh sách, Lịch hoặc Dashboard. Điểm đặc biệt là mọi dữ liệu đều được lưu dưới dạng file Markdown thuần tuý, không bị khóa vào bất kỳ định dạng đóng nào.

⚙️ 2. Hướng dẫn cài đặt

  1. Cài đặt: Tải thủ công từ Github hoặc qua Community Plugins (tìm "Pie Tasks").
  2. Kích hoạt: Vào Settings → Community plugins và bật Pie Tasks lên.
  3. Thiết lập nhanh: Vào Settings → Pie Tasks → Quick setup. Plugin sẽ tự động tạo các file mẫu cần thiết (như TASKS.md, People.md) mà không ảnh hưởng đến dữ liệu hiện tại của bạn.
  4. Mở bảng điều khiển: Bấm vào biểu tượng dấu ✓ trên thanh công cụ bên trái (ribbon) hoặc dùng lệnh Pie Tasks: open live board.

📝 3. Cấu trúc file TASKS.md

Pie Tasks đọc công việc trực tiếp từ file Markdown. Dưới đây là cách bạn định dạng nội dung:

Tạo Cột (Lane)

Sử dụng tiêu đề cấp 2 (##) để tạo các cột trong bảng Kanban. Bạn có thể dùng Emoji ở đầu để làm biểu tượng cho cột.

## 📌 Đang làm ## ✅ Hoàn thành

Tạo Công Việc (Task)

Sử dụng cú pháp checkbox mặc định của Markdown. Thêm các token ở cuối dòng để khai báo các thuộc tính của công việc.

- [ ] **Tên công việc** 👤 An 📅 2026-07-05 ⏰ 14:00–16:00 Đang làm 🔴

Danh sách các token hỗ trợ:

👤 Tên Người phụ trách (Ví dụ: 👤 An, Bình)
📅 YYYY-MM-DD Ngày/Hạn chót
⏰ HH:MM–HH:MM Khung giờ thực hiện
Trạng thái Chọn 1 trong: Đang chờ, Đang làm, Chờ duyệt, Hoàn thành, Tạm dừng, Hủy, Lỗi...
60% Mức độ hoàn thành
next: ... Ghi chú việc kế tiếp (1 dòng)
output: [[note]] Liên kết tới ghi chú hoặc tài liệu liên quan
🔴 Đánh dấu ưu tiên cao

Lưu ý: Để đánh dấu công việc đã xong, đổi - [ ] thành - [x] và có thể thêm ✅ YYYY-MM-DD để lưu ngày hoàn thành.

👥 4. Quản lý nhân sự (People.md)

Bạn có thể tạo một file People.md (hoặc tuỳ chọn trong Settings) để quản lý danh sách những người phụ trách công việc. Việc này giúp tự động gợi ý tên khi thêm người (👤).

File này dùng định dạng bảng Markdown:

| Tên | ID | Username | Phòng ban | |------|-------|----------|-----------| | An | 01 | an_dev | Dev | | Bình | 02 | binh_mkt | Marketing |

Chỉ cột Tên là bắt buộc. ID dùng để đồng bộ với các hệ thống ngoài (nếu có).

💡 5. Tính năng nổi bật & Mẹo

  • Đồng bộ hai chiều: Khi bạn kéo thả thẻ trong bảng Kanban, file Markdown sẽ tự động cập nhật lại tiêu đề (Lane) và các thuộc tính tương ứng.
  • Nhiều Boards: Bạn có thể tạo nhiều board khác nhau (Cá nhân, Công việc, Dự án X) trong Settings, mỗi board trỏ tới một file Markdown riêng biệt.
  • Bốn góc nhìn (Views): Dễ dàng chuyển đổi qua lại giữa dạng Kanban, Danh sách (List), Lịch tháng (Calendar) và Thống kê (Dashboard).
  • Tương thích Kanban Plugin: Thêm kanban-plugin: board vào frontmatter nếu bạn muốn file cũng chạy được với các plugin Kanban khác.
